# User Stories: Moduł Zarządzania Sesjami

**Jako** Mistrz Gry (GM)
**Chcę** mieć możliwość stworzenia nowej sesji podając jej nazwę
**Aby** stworzyć wyizolowane środowisko (kontener) dla konkretnej kampanii.

**Jako** Mistrz Gry
**Chcę** widzieć listę wszystkich moich sesji na ekranie startowym
**Aby** móc łatwo wybrać tę, którą chcę aktualnie poprowadzić.

**Jako** Mistrz Gry
**Chcę** móc zmienić nazwę istniejącej sesji lub ją usunąć (z potwierdzeniem)
**Aby** utrzymać porządek w moich kampaniach i pozbyć się tych zakończonych.

**Jako** Mistrz Gry
**Chcę**, aby po wejściu w sesję aplikacja automatycznie ładowała jej ostatni stan (postacie, logi)
**Aby** móc płynnie kontynuować grę od momentu, w którym ją zakończyliśmy.
