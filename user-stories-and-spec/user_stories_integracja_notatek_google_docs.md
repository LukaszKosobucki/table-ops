# User Stories: Integracja Notatek Zewnętrznych (Google Docs / Smart Embed)

---

## 1. Dostęp do Zewnętrznych Notatek Sesyjnych Mistrza Gry

**Jako** Mistrz Gry  
**Chcę** móc przypisać bezpośredni link do mojego dokumentu w Google Docs (lub folderu na Google Drive) do aktywnej sesji RPG  
**Aby** mieć błyskawiczny dostęp do całego przygotowanego scenariusza, opisów lokacji i lore bez konieczności kopiowania i wklejania setek stron tekstu do bazy danych aplikacji.

**Jako** Mistrz Gry  
**Chcę** mieć możliwość szybkiego otwarcia przypisanego dokumentu w nowej karcie jednym kliknięciem (`Otwórz w Google Docs ↗`)  
**Aby** wygodnie edytować notatki w dedykowanym edytorze na osobnym ekranie podczas prowadzenia sesji.

**Jako** Mistrz Gry  
**Chcę** móc podejrzeć zawartość Google Docs bezpośrednio wewnątrz TableOps w wysuwanym panelu bocznym lub oknie modalnym (tryb Smart Embed)  
**Aby** sprawdzić kluczowe informacje, imię NPC-a czy statystyki bez opuszczania pulpitu zarządzania walką i inicjatywą.

**Jako** Mistrz Gry  
**Chcę**, aby aplikacja przechowywała wyłącznie lekki link URL do dokumentu w bazie danych  
**Aby** nie zużywać limitów dyskowych bazy PostgreSQL ciężkimi plikami i zachować pełną niezawodność oraz szybkość działania aplikacji.
